# P04 — Server MongoDB và tài khoản nội bộ

Phụ thuộc: P01.

## Mục tiêu

Axum backend, auth/session/invitation, workspace/membership/roles, private Mongo topology, migrations/indexes và transaction repository.

## Đầu vào

Đọc quyết định hiệu lực, master prompt, architecture, dependency report, yêu cầu được gán dưới đây và các screen JSON/MD/ảnh thực có liên quan. Không đọc cả 316 ảnh vào một lần; lấy inventory rồi scope theo task.

## Bàn giao

server binary/image, backend OpenAPI, Mongo indexes, auth/permission integration tests

## Gate kết thúc

Invitation one-time, Viewer bị chặn ở server, credentials không trên desktop; commit/rollback/retry tests thật.
