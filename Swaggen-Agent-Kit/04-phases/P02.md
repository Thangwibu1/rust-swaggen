# P02 — Lõi API cá nhân bản A

Phụ thuộc: P01.

## Mục tiêu

Collection/folder/request, ordered params/headers/body, auth A, variables/secrets, production confirm, response/history/file, tabs/recovery.

## Đầu vào

Đọc quyết định hiệu lực, master prompt, architecture, dependency report, yêu cầu được gán dưới đây và các screen JSON/MD/ảnh thực có liên quan. Không đọc cả 316 ảnh vào một lần; lấy inventory rồi scope theo task.

## Bàn giao

personal desktop app, HTTP fixture server, request tests, screen evidence

## Gate kết thúc

Luồng soạn→gửi→response→restart chạy thật; 20MB không treo, timeout/cancel/TLS/encoding đúng.
