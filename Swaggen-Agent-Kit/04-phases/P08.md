# P08 — Kiểm thử, mock và developer tools bản B

Phụ thuộc: P07.

## Mục tiêu

Runner/dependencies/data, reports/reproducible runs, contract validation, local/shared mock, CLI/JUnit, GraphQL cơ bản và SSE có bounded memory.

## Đầu vào

Đọc quyết định hiệu lực, master prompt, architecture, dependency report, yêu cầu được gán dưới đây và các screen JSON/MD/ảnh thực có liên quan. Không đọc cả 316 ảnh vào một lần; lấy inventory rồi scope theo task.

## Bàn giao

CLI + runner engine + mock, JSON/JUnit reports, reproducible fixtures

## Gate kết thúc

Cancel/fail/skipped đúng; seed deterministic; CI exit code đúng; server SSRF policy trước mock/fetch.

## Checklist thực thi

- Kiểm tra dependency/SDK của phase trước khi dùng API mới.
- Thực hiện UI → domain → storage/API thật theo luồng.
- Unit/integration/E2E thích hợp; visual Windows nếu UI; benchmark nếu hot path.
- Cập nhật traceability/status/risks/next task và hướng dẫn chạy.
- Commit khi được môi trường làm việc cho phép; không giả tạo commit ID.
- Nếu gate blocked, tiếp tục phần độc lập nhưng không đánh dấu phase hoàn thành.
