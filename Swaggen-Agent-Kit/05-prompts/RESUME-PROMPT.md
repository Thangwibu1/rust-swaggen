# Prompt tiếp tục

Tiếp tục Swaggen theo AGENTS.md và MASTER-PROMPT.md. Đọc decisions, phase status, traceability, checkpoint/ADR/reports mới nhất và git diff nếu có. Xác minh việc đã hoàn thành từ evidence; giữ code hiện có, không reset scaffold hoặc ghi đè lựa chọn đã chốt.

Báo ngắn phase hiện tại, gate còn thiếu, blocker thật. Kiểm tra dependency/toolchain/topology cho phần tiếp theo rồi thực hiện tác vụ nhỏ tiếp theo có giá trị end-to-end. Giữ no-web-frontend, Rust toàn ứng dụng, MongoDB transactions, Coolify VPS, local offline, secret isolation. Cập nhật evidence/status và tiếp tục tới khi phạm vi được giao hoàn thành. Không nói "test pass" cho test chưa chạy.
