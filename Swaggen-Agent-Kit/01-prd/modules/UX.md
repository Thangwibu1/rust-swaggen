# UX — Yêu cầu nguồn

## UX01 · A · Bố cục làm việc

Sidebar project, tab request hoặc spec, vùng response; kéo đổi kích thước và nhớ bố cục từng máy.

## UX02 · A · Tab và khôi phục

Mở nhiều tab, ghim và đóng nhóm; khôi phục nháp và tab sau restart hoặc crash.

## UX03 · A · Phím tắt

Ctrl Enter gửi, Ctrl S lưu nháp, Ctrl P tìm nhanh; xem danh sách phím và tránh xung đột khi đang gõ trong editor.

## UX04 · B · Command palette

Tìm hành động, đổi environment, mở request và chuyển workspace qua bàn phím.

## UX05 · A · Hiển thị Windows

Hỗ trợ DPI scaling nhiều màn hình, resize và cửa sổ nhỏ; chữ và control không bị cắt ở mức zoom thông dụng.

## UX06 · B · Theme và ngôn ngữ

Theme sáng tối, lựa chọn tiếng Việt hoặc tiếng Anh; giữ nguyên tên biến và nội dung API của người dùng.

## UX07 · B · Khả năng truy cập

Focus rõ, điều hướng bàn phím và nhãn control; prototype kiểm tra screen reader trên UI được chọn.

## UX08 · B · Mở file và liên kết

Mở file project hoặc đặc tả từ Explorer, kéo thả import; deep link không tự chạy request hay lệnh hệ thống.

## UX09 · A · Trạng thái kết nối

Hiện server đang dùng, offline và số thay đổi chờ; lỗi sync không chặn soạn request cục bộ.

## UX10 · A · Quản lý dữ liệu máy

Xem dung lượng history cache downloads, đổi thư mục dữ liệu và đặt retention; dọn cache không xóa project hoặc secret.
